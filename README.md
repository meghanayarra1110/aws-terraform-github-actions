# AWS Infrastructure Automation with Terraform & GitHub Actions

## Overview

This project demonstrates Infrastructure as Code (IaC) and automated AWS infrastructure deployment using Terraform and GitHub Actions.

The infrastructure is provisioned automatically on AWS and includes a custom VPC, public subnet, Internet Gateway, route table, security group, and EC2 instance.

A Dockerized Nginx application is automatically installed and deployed on the EC2 instance.

## Architecture

GitHub → GitHub Actions → Terraform → AWS VPC → Public Subnet → Security Group → EC2 → Docker → Nginx

## Technologies Used

- Terraform
- AWS
- GitHub Actions
- Docker
- Linux
- Git & GitHub
- Nginx

## AWS Infrastructure

Terraform provisions:

- Custom VPC
- Public subnet
- Internet Gateway
- Public route table
- Route table association
- Security group
- EC2 instance

## Application Deployment

The EC2 instance uses Terraform `user_data` to:

1. Update the system
2. Install Docker
3. Start the Docker service
4. Pull the Nginx Alpine image
5. Run the Nginx container
6. Expose the application on port 80

## Terraform Workflow

```text
terraform init
       ↓
terraform fmt
       ↓
terraform validate
       ↓
terraform plan
       ↓
terraform apply
       ↓
AWS Infrastructure
```

## Deployment Result

The Terraform configuration successfully creates the AWS infrastructure and deploys an Nginx web application inside a Docker container.

The application is accessible through the public IP address generated by Terraform.
